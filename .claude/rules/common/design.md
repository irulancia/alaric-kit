# Design System

The tokens live in `src/app.css` (`:root`), generated by the configurator (`.claude/scripts/configurator/configurator.html`, "Save src/app.css") — never edited by hand. `<body class="ds-root">` scopes the element styles. The full reference, `design-reference.md`, loads by itself when a `.svelte`, `.css` or `.html` file is read or edited; read it before building a component or a page. Everything `app.css` ships is listed under "What exists" below.

## Never
- A literal colour, size, radius, shadow or z-index in a component: use a token (`check-design-tokens.sh` blocks the obvious ones). A missing token is added to `app.css` through the configurator, not hardcoded once.
- A component the system already has, rebuilt: check "What exists" below first. Something it really doesn't have is reported, and the owner is asked whether it goes in the design system or only in the project, before anything is built (the reference's Part 2) — never a quiet local version.
- `--accent` as text or an outline — it is a fill only (on a light primary it is illegible).
- Pure black text, colour alone to carry a meaning (an error also has an icon and words), a fixed margin on a reusable component.

## Colour
- Primary has three roles: `--accent` (fills, with `--on-accent` text), `--accent-ui` (outlines, switches, progress, focus; 3:1), `--accent-text` (links, labels; 4.5:1). Link hover: `--accent-text-hover`, never `--accent-hover`.
- Neutrals: `--bg-primary` (page), `--bg-card` (raised), `--bg-surface`, `--bg-hover`; `--text-primary`, `--text-secondary`, `--text-label`; `--border`, `--border-subtle`, `--border-control` (3:1, for a control's outline).
- State: `--success` / `--error` / `--warning` / `--info`, text on their tints in the `-strong` variant. `--disabled-bg`, `--disabled-text`, `--overlay`.
- Focus: `outline: 2px solid var(--focus-ring); outline-offset: 2px` — an outline, not a box-shadow.

## Type
- `--font-display` for H1–H3 and `--text-display`, `--font` for the rest. Sizes only from the scale: `--text-display`, `--text-h1..h3`, `--text-body`, `--text-small`, `--text-xs`. H4–H6 are `--text-body` + semibold, not new sizes.
- Text you read is `--text-body`; a control's text (buttons, tabs, menu, toggle, switch labels) is `--text-ui`. Table cells are `--text-small`.
- Weights `--weight-regular / -medium / -semibold / -bold`; line height `--leading-tight` (headings) / `--leading-loose` (text).

## Space and shape
- Spacing only from `--space-0..12`. Padding inside something with a background or border; `gap` between children; the parent positions a component.
- Proximity: inside a group half the gap between groups (`--space-2` vs `--space-3` in a card, `.card-group`).
- Radius by role: `--radius-control` (buttons), `--radius-field`, `--radius-chip`, `--radius-surface` (cards, menus, tables), `--radius-overlay` (dialogs), `--radius-pill`. Nested in a rounded container: its radius minus the padding.
- Heights: `--control-height-sm` / `--control-height` / `--control-height-lg`, `--row-height`. Shadows `--shadow-sm / -md / -hover`; layers `--z-dropdown / -overlay / -modal / -toast`. Icons are in `app.css`: `<span class="icon icon-house" aria-hidden="true"></span>` (`.icon-sm` / `.icon-lg` for size; the names are the `.icon-*` rules at the end of the file) — never drawn by hand or copied from elsewhere.

## Which component
- One of 2–6 options → `.segmented`; on / off → `.switch`; a pressed tool → `.toggle`; related separate actions → `.btn-group`; several ways to do one thing → one button with a menu.
- Buttons `.btn` + `.btn-primary / -secondary / -tertiary / -destructive / -ghost`, sizes `.btn-sm`, default, `.btn-lg` (a call to action, never inside a card). One primary per view. Icon-only buttons have an `aria-label` and a tooltip (`.has-tooltip`).
- Text fields are `.field` (floated label); a control that isn't a text field sits in a `.form-row` with its label above. A control that doesn't apply now is disabled with its reason (`.reason`), not hidden.
- A dialog is a real `<dialog class="dialog">` opened with `showModal()`; a drawer the same. Toasts in one `.toast-region`. Menus and popovers carry the `popover` attribute.
- Page layouts (app shell, page header, form sections, landing bands) come from the layout classes in `app.css`; the content's maximum width is the project's choice.
- Lists that can be empty show an empty state: icon, what is missing, one sentence, the one action that fills it.
